# Explicit Auto Layout Reference Placement Regression Fixture 1

The fixture is a DEV-only diagnostic pair. It is not a public sample and does
not change the normal Product fixture set.

## Reproduction

Open the reference URL, confirm the saved-coordinate arrangement, then use
`More -> Auto Layout` and wait for `Review Auto Layout`. The same graph without
coordinates is available from the coordinate-less URL for Initial Automatic
Display comparison.

| --- | --- |
| Reference EN | `http://127.0.0.1:5176/e2r-liaison-scape/?acceptance-fixture=reference-regression&acceptance-locale=en` |

On 2026-09-17 the reference EN surface loaded 12 entities and 19 relations,
with all 12 saved positions read from `liaisonscape-graph`. The reference view
showed two vertically separated local clusters and a right-side bridge /
observatory corridor. Explicit Auto Layout reached Running and then Review
Preview. The preview rearranged the same nodes into a central circular
arrangement and displayed the existing presentation-quality warning. The
reference-to-preview difference is therefore reproducible, but this checkpoint
does not treat visual inspection as a final Human Review disposition.

## Evidence boundary

The machine report is generated by:

```text
node --experimental-strip-types tools/explicit-auto-layout-reference-placement-regression-fixture1.mjs
```

It runs the current `runExplicitAutoLayoutOperation`, Product presentation
evaluation, and the coordinate-less `settleInitialPlacement` control. The
selected Preview is complete, finite, Product-evaluated, and deterministic.
Machine metrics do not show a solver-only regression: the reference and Preview
have equal reported crossings in this diagnostic measurement, while Preview has
zero label-route hits versus two for the reference. The reference has the
intended wider cluster extent, and the aggregate score is lower for the
reference. Responsibility remains mixed among candidate geometry, Product
presentation, and the chosen reference baseline.

Human Review remains `READY_TO_REVIEW_NOT_JUDGED`; no PASS/QUALIFIED/FAIL is
inferred. Pin/Preview/Save lifecycle acceptance remains separate and unchanged.
