# LiaisonScape ユーザーガイド

LiaisonScapeは、データセット（Dataset）に含まれるエンティティ（Entity）と、それらのつながりをグラフとして見たり、編集したりするアプリケーションです。
このガイドでは、データの細かな仕様を先に学ぶのではなく、画面を操作しながら基本的な使い方を説明します。

## このガイドで使う言葉

- データセット（Dataset）：エンティティやつながりをまとめたデータです。
- エンティティ（Entity）：人物、組織、場所、物など、グラフ上でノードとして表示される対象です。
- つながり（Relation）：あるエンティティから別のエンティティへのつながりです。向きがあります。
- ノード：グラフ上に表示されるエンティティです。
- 線：エンティティ同士のつながりをグラフ上に表示したものです。

画面上の表示やボタンでは、現在の日本語UIに合わせて一部の用語を使います。たとえば「Entity」は「エンティティ」、「Relation」は「つながり」として説明します。

## Homeから始める

Homeには、主に次の操作があります。

- 「新しいDataset」：空のDatasetを作成します。
- 「E2R Datasetを開く」：手元のE2R JSONファイルを開きます。
- 「サンプルDatasetを開く」：LiaisonScapeのサンプルを開きます。
- 「English」：表示言語を切り替えます。
- 「クレジット」：Creditsを表示します。

初めて使う場合は、「サンプルDatasetを開く」から始めると、グラフの表示や編集をすぐに試せます。

## Datasetを開く

「E2R Datasetを開く」を選び、E2R JSONファイルを指定します。読み込みに成功すると、エンティティがノードとして、エンティティ同士のつながりが線として表示されます。

日本語UIでは「サンプルDatasetを開く」から、日本語向けの「灯台修復プロジェクト」のサンプルを開けます。このサンプルには複数のエンティティ、イベント（Event）、エンティティ同士のつながりが含まれているため、グラフの操作を試すのに適しています。

イベント（Event）につながるつながりはデータセットには保持されますが、現在のグラフ表示ではエンティティ同士の線としては表示されません。

## グラフを見る

- ノード本体をクリックまたはタップすると、そのエンティティを選択できます。エンティティの名前や説明の文字をクリックまたはタップすると、その親エンティティを選択できます。
- つながりの線をクリックまたはタップすると、そのつながりを選択できます。
- つながりに名前がある場合、線の近くにその名前が表示されます。この文字を「つながりの名前」と呼びます。
- つながりの名前をクリックまたはタップすると、その親のつながりを選択できます。
- つながりの線に付いた矢印は、つながりの向きを示します。
- グラフ上でドラッグすると、表示範囲を移動できます。
- グラフ上でCtrlキーを押しながらマウスホイールを上に回すと拡大、下に回すと縮小できます。
- 画面上の「拡大」「縮小」でもズームできます。
- 「表示をリセット」で表示を初期状態に戻せます。

保存された位置がないノードには、見やすく表示するための初期位置が自動的に割り当てられます。この初期位置の割り当てだけではデータセットは変更されません。

## エンティティを作成・編集する

### エンティティを作成する

「エンティティを追加」を選び、名前と説明を入力して「エンティティを作成」を押します。名前が空でも作成できますが、あとで見分けやすい名前を付けることをおすすめします。

別の方法として、グラフの空白部分のコンテキストメニューを開き、「エンティティを追加」を選べます。マウスやトラックパッドでは右クリック、タッチ操作では空白部分の長押しで開きます。

作成直後のノードは、一時的な表示位置に置かれます。必要に応じてグラフ上で移動し、座標を保存してください。

### エンティティを編集する

エンティティを選択し、利用できる詳細操作から「Entity 詳細」を開きます。エンティティを右クリックまたは長押しして、コンテキストメニューの「詳細を開く」を選ぶこともできます。「名前」または「説明」を編集し、「変更を保存」で保存します。

既存のエンティティを編集しても、LiaisonScapeが扱っていない追加データは可能な限り保持されます。

### エンティティを削除する

エンティティの詳細から削除できます。ただし、そのエンティティにつながるつながりがある場合は、誤削除を防ぐため削除できません。先に関連するつながりを確認して削除してください。

## つながりを作成・編集する

### つながりを作成する

「つながりを追加」を選び、「つながり元」と「つながり先」にエンティティを指定します。必要に応じて名前と説明を入力し、「つながりを作成」を押します。

つながりには向きがあります。「つながり元」から「つながり先」へのつながりとして作成されるため、逆向きにしたい場合は「つながり元」と「つながり先」を入れ替えます。

同じエンティティを「つながり元」と「つながり先」に指定する、同じエンティティ自身へのつながりや、同じ組み合わせに複数のつながりを作成することもできます。

別の方法として、ノード端の接続用ハンドルから別のノードへドラッグし、接続先で離して作成フォームを完了し、保存できます。

### つながりを編集する

つながりを選択し、利用できる詳細操作から「Relation 詳細」を開きます。つながりを右クリックまたは長押しして、コンテキストメニューの「詳細を開く」を選ぶこともできます。エンティティ同士のつながりでは、「つながり元」と「つながり先」を変更できます。名前や説明を編集したら「変更を保存」を押します。

### つながりを削除する

つながりの詳細から削除できます。削除する前に、向きや名前を確認してください。

## ノードを移動して位置を保存する

ノードをドラッグすると、グラフ上の位置を変更できます。移動しただけでは、Dataset内の座標は確定しません。

位置を残したい場合は、ツールバーの「座標を保存」を押します。保存できない形式の座標情報がデータセットに含まれている場合は、移動位置は一時的な表示にとどまります。その場合、画面に表示される案内を確認してください。

つながりの線の経路や、エンティティの名前・説明およびつながりの名前の表示位置は、ノードの座標保存とは別の保留中の表示作業です。「座標を保存」では保存されません。

## ラベルやつながりの配置を調整する

ノードのラベルをドラッグするとラベルを手動配置できます。つながりの線をドラッグすると、ドラッグ開始時にそのつながりが選択され、事前選択なしで経路を手動調整できます。つながりの名前をドラッグするとラベルを手動配置できます。これらは「座標を保存」では保存されない保留中の表示作業です。対象のコンテキストメニューを右クリックまたは長押しで開き、「自動配置に戻す」を選ぶとリセットできます。

## Datasetを書き出す

「E2R JSONを書き出す」を押すと、現在のDatasetを確認してからE2R JSONとしてダウンロードします。

書き出し時に問題が見つかった場合は、画面に検証メッセージが表示され、ダウンロードされないことがあります。メッセージを確認して、エンティティやつながりの内容を修正してください。

保存していない一時的なノード位置、ズーム、パン、選択状態などの画面操作は、データセットのデータそのものとは別の表示状態です。「座標を保存」で保存したノード位置はデータセットに含まれ、書き出されたファイルにも反映されます。その他の一時的な表示状態は書き出されません。

## Datasetを安全に置き換える

手元のDatasetを開く、サンプルDatasetを開く、「新しいDataset」を作成する操作では、正しい候補Datasetが用意できた後に現在のDatasetが置き換わります。失われる可能性のある作業がある場合は、置き換えの確認が表示されます。

現在の作業状態に応じて、次の操作を選べます。

- 「キャンセル」：現在のDatasetと作業を維持します。
- 「作業を破棄して続行」：保存していない作業を破棄して候補Datasetを開きます。
- 「書き出して続行」：変更済みDatasetで利用できます。現在のDatasetを書き出してから候補Datasetを開きます。
- 「Datasetを書き出す」：変更済みの内容と保留中の作業が両方ある場合に利用できます。現在のDatasetの書き出し可能な内容を書き出しますが、保留中の作業をDatasetに確定せず、この操作だけでは候補Datasetへ置き換えません。現在のDataset、保留中の作業、候補Datasetはそのまま維持されます。

失われる可能性のある作業がなければ、確認なしで置き換えられます。JSONが不正な場合や、Datasetの検証に失敗した場合は、現在のDatasetを置き換えません。

## ブラウザーの再読み込み・終了時の保護

保存していないDatasetの変更や保留中の作業が失われる可能性がある場合、再読み込み、ページを閉じる操作、ページから移動する操作で、ブラウザー標準の警告が表示されることがあります。表示される文言や操作はブラウザーによって異なります。この警告は一時的な画面状態がすべて保存されることを意味するものではなく、書き出しや作業の完了が必要な状態を示します。

## handoff URLからDatasetを開く

URLに次の形式のfragmentがある場合、LiaisonScapeは起動時に公開Datasetを開けます。

```text
#datasetUrl=<percent-encoded absolute HTTPS URL>
```

リモートのリソースは、HTTPSで公開され、ブラウザーからのリクエストをCORSで許可している必要があります。非公開または認証が必要なリソースは、このv0の対象外です。handoffは起動時だけ処理され、後からfragmentを変更しても、開いているDatasetは切り替わりません。

handoff URLが不正、取得不能、不正なJSON、またはDataset検証失敗の場合、LiaisonScapeはHomeに失敗を表示し、サンプルなど別のDatasetを暗黙に開きません。

handoffに成功した後は、Datasetを取得した場所への参照として`datasetUrl` fragmentを維持します。これはDatasetの同一性ではなく、現在の未書き出し編集や画面状態を表すものでもありません。handoffしたDatasetを手元のDataset、サンプル、または新しいDatasetに正常に置き換えた場合は、`datasetUrl`だけを削除し、他のfragmentパラメーターは保持します。

## 検証メッセージ

Datasetを開くときや書き出すとき、LiaisonScapeはデータの整合性を確認します。

- 問題がない場合は、そのまま操作や書き出しを続けられます。
- 問題がある場合は、メッセージの内容を確認してください。
- LiaisonScapeが表示に使わない情報でも、読み込み後の保存で可能な限り保持されます。

検証メッセージは、E2R Datasetを安全に扱うための案内です。内容が分からない場合は、元のファイルを保存したうえで、メッセージと一緒に確認してください。

## 現在のMVPの範囲

現在のLiaisonScapeでは、エンティティとエンティティ同士のつながりの作成・編集・削除、つながり元・つながり先の変更、同じエンティティ自身へのつながり、同じ組み合わせへの複数のつながり、グラフ上からのエンティティやつながりの直接作成、ノード位置の保存、データセットの書き出しに対応しています。

イベントをノードとして表示する機能、イベントの作成・編集・削除、操作の取り消し・やり直し、つながりの高度な表示設定などは、今後の拡張対象です。
