# LiaisonScape ユーザーガイド

LiaisonScapeは、データセット（Dataset）に含まれるエンティティ（Entity）と、それらのつながりをグラフとして見たり、編集したりするアプリケーションです。
このガイドでは、データの細かな仕様を先に学ぶのではなく、画面を操作しながら基本的な使い方を説明します。

## このガイドで使う言葉

- データセット（Dataset）：エンティティやつながりをまとめたデータです。
- エンティティ（Entity）：人物、組織、場所、物など、グラフ上でノードとして表示される対象です。
- つながり（Relation）：あるエンティティから別のエンティティへのつながりです。向きがあります。
- ノード：グラフ上に表示されるエンティティです。
- つながり：グラフ上の線として表示されるRelationです。

画面上の表示やボタンでは、現在の日本語UIに合わせて一部の用語を使います。たとえば「Entity」は「エンティティ」、「Relation」は「つながり」として説明します。

## Homeから始める

Homeには、主に次の操作があります。

- 「新しいDataset」：空のDatasetを作成します。
- 「E2R Datasetを開く」：手元のE2R JSONファイルを開きます。
- 「サンプルDatasetを開く」：LiaisonScapeのサンプルを開きます。
- 「日本語」：表示言語を切り替えます。
- 「クレジット」：Creditsを表示します。

初めて使う場合は、「サンプルDatasetを開く」から始めると、グラフの表示や編集をすぐに試せます。

## Datasetを開く

「E2R Datasetを開く」を選び、E2R JSONファイルを指定します。読み込みに成功すると、Entityがノードとして、Entity同士のRelationが線として表示されます。

日本語UIでは「サンプルDatasetを開く」から、日本語向けの「灯台修復プロジェクト」のサンプルを開けます。このサンプルには複数のEntity、Event、Entity同士のつながりが含まれているため、グラフの操作を試すのに適しています。

EventにつながるRelationはデータセットには保持されますが、現在のグラフ表示ではエンティティ同士の線としては表示されません。

## グラフを見る

- ノード本体をクリックまたはタップすると、そのEntityを選択できます。Entityの名前や説明の文字をクリックまたはタップすると、そのEntityの詳細を開けます。
- つながりの線をクリックまたはタップすると、そのつながりを選択できます。選択した線をドラッグすると、線の曲がり方を一時的に調整できます。
- つながりに名前がある場合、線の近くにその名前が表示されます。この文字を「つながりの名前」と呼びます。
- つながりの名前をクリックまたはタップすると、そのつながりの詳細を開けます。名前がないつながりは、まず線を選択してから詳細操作を行います。
- Relationの矢印は、つながりの向きを示します。
- グラフ上でドラッグすると、表示範囲を移動できます。
- Entityの名前や説明の文字をドラッグすると、文字の表示位置を調整できます。これは画面上の表示だけに反映され、Datasetには保存されません。
- グラフ上でCtrlキーを押しながらマウスホイールを上に回すと拡大、下に回すと縮小できます。
- 画面上の「拡大」「縮小」でもズームできます。
- 「表示をリセット」で表示を初期状態に戻せます。

保存された位置がないノードには、見やすく表示するための初期位置が自動的に割り当てられます。この初期位置の割り当てだけではデータセットは変更されません。

## Entityを作成・編集する

### Entityを作成する

「エンティティを追加」を選び、名前と説明を入力して「エンティティを作成」を押します。名前が空でも作成できますが、あとで見分けやすい名前を付けることをおすすめします。

作成直後のノードは、一時的な表示位置に置かれます。必要に応じてグラフ上で移動し、座標を保存してください。

### Entityを編集する

ノードを選択して「Entity 詳細」を開き、「名前」または「説明」を編集します。「変更を保存」で保存します。

既存のEntityを編集しても、LiaisonScapeが扱っていない追加データは可能な限り保持されます。

### Entityを削除する

Entityの詳細から削除できます。ただし、そのEntityにつながるRelationがある場合は、誤削除を防ぐため削除できません。先に関連するRelationを確認して削除してください。

## Relation（つながり）を作成・編集する

### Relationを作成する

「つながりを追加」を選び、「つながり元」と「つながり先」にEntityを指定します。必要に応じて名前と説明を入力し、「つながりを作成」を押します。

つながりには向きがあります。「つながり元」から「つながり先」へのつながりとして作成されるため、逆向きにしたい場合は「つながり元」と「つながり先」を入れ替えます。

同じEntityを「つながり元」と「つながり先」に指定する自己Relationや、同じEntityの組み合わせに複数のRelationを作成することもできます。

### Relationを編集する

線またはつながりの名前からRelationを選び、「Relation 詳細」を開きます。Entity同士のRelationでは、「つながり元」と「つながり先」を変更できます。名前や説明を編集したら「変更を保存」を押します。

### Relationを削除する

Relationの詳細から削除できます。削除する前に、向きや名前を確認してください。

## グラフを直接編集する

グラフ上で操作しながらEntityとRelationを作成できます。

- マウスでグラフ上の空白を右クリックすると操作メニューが開き、「エンティティを追加」から新しいEntityを作成できます。
- タッチ操作では、グラフ上の空白を長押しすると同じ操作メニューが開きます。
- ノードの端にある接続用の小さな丸から、別のノードへドラッグするとRelationの作成を開始できます。接続先のノード上で指やマウスを離し、名前や説明を入力して保存します。
- ノードやつながりを右クリックすると、それぞれの詳細を開けます。タッチ操作では長押しで開けます。
- 作成途中の操作は、確認して保存するまでデータセットに確定しません。

現在のUIで表示される案内に従って、名前、つながり元、つながり先などを確認してから保存してください。

## ノードを移動して位置を保存する

ノードをドラッグすると、グラフ上の位置を変更できます。移動しただけでは、Dataset内の座標は確定しません。

位置を残したい場合は、ツールバーの「座標を保存」を押します。保存できない形式の座標情報がデータセットに含まれている場合は、移動位置は一時的な表示にとどまります。その場合、画面に表示される案内を確認してください。

つながりの線の曲がり方や、Entityの名前・説明およびつながりの名前の表示位置は、現在の表示状態に関する設定です。ノードの座標保存とは別に扱われます。

## Datasetを書き出す

「E2R JSONを書き出す」を押すと、現在のDatasetを確認してからE2R JSONとしてダウンロードします。

書き出し時に問題が見つかった場合は、画面に検証メッセージが表示され、ダウンロードされないことがあります。メッセージを確認して、EntityやRelationの内容を修正してください。

保存していない一時的なノード位置、ズーム、パン、選択状態などの画面操作は、データセットのデータそのものとは別の表示状態です。「座標を保存」で保存したノード位置はデータセットに含まれ、書き出されたファイルにも反映されます。その他の一時的な表示状態は書き出されません。

## 検証メッセージ

Datasetを開くときや書き出すとき、LiaisonScapeはデータの整合性を確認します。

- 問題がない場合は、そのまま操作や書き出しを続けられます。
- 問題がある場合は、メッセージの内容を確認してください。
- LiaisonScapeが表示に使わない情報でも、読み込み後の保存で可能な限り保持されます。

検証メッセージは、E2R Datasetを安全に扱うための案内です。内容が分からない場合は、元のファイルを保存したうえで、メッセージと一緒に確認してください。

## 現在のMVPの範囲

現在のLiaisonScapeでは、EntityとEntity同士のRelationの作成・編集・削除、Relationの端点編集、自己Relation、並列Relation、グラフ上での直接作成、ノード位置の保存、Datasetの書き出しに対応しています。

Eventをノードとして表示する機能、Eventの作成・編集・削除、Undo/Redo、Relationの高度な表示設定などは、今後の拡張対象です。
